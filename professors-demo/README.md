# 2027년 1학기 교수 배정 현황

서울대학교 공개 수강편람의 2027년 1학기 강좌를 읽어 만든 비공식 조회 페이지입니다. 강좌 검색, 학과·과정·교수 배정 필터, CSV 다운로드를 지원합니다.

`crawl_snu.py`는 로그인 없이 공식 강좌 검색을 10개씩 조회하고, 총 강좌 수와 중복을 확인한 뒤에만 `courses.json`을 갱신합니다. 수집 중 오류가 나면 기존 데이터가 유지됩니다. 한 페이지마다 0.8초 간격을 둡니다.

저장소의 `.github/workflows/update-snu-courses.yml`은 매일 06:17 및 18:17 KST에 수집 후 GitHub Pages로 배포합니다. GitHub Actions의 실행 지연이나 공식 사이트 장애가 있으면 갱신이 늦어질 수 있습니다. 실제 수강 정보는 [서울대학교 수강편람](https://sugang.snu.ac.kr/sugang/cc/cc100InterfaceSrch.action)에서 다시 확인하세요.

공식 검색 결과에 없는 단과대와 학년은 표시하지 않습니다. 이 페이지는 서울대학교 공식 서비스가 아닙니다.
