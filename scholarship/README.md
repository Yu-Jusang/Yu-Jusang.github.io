# 장학 한눈에

서울대생용 장학 공고 탐색 및 개인 신청 준비 도구.

Live: https://yu-jusang.github.io/scholarship/

## 기능

- 공식 공지 기반 장학금 7건 (제도 안내와 마감 공고 포함), 검색·분야·마감 필터
- 학위·학적·연수 계획과 명시된 조건을 브라우저에서 비교. 일부 부합을 최종 지원 가능으로 표시하지 않음
- 근거, 미확인 조건, 공식 원문 및 신청 경로
- 개인 지원함, 체크리스트, 메모, 마감일 ICS 다운로드
- 한국시간 마감 처리, 날짜만 확인된 공고는 시각 확인 안내
- 개인정보는 localStorage `snu-scholarship-desk-v1`에만 저장. 서버 전송 없음

## 자료 상태

2026-10-18 공식 공개 웹페이지에서 수동 확인한 초기 자료다. 현재 자동 수집·LLM 호출·마이스누 로그인 연동은 없다. 첨부 요강을 확인하지 못한 항목은 세부 조건과 모집 여부가 미확인임을 표시한다. 재단별 지급 성격이 미확인인 경우 분야는 탐색 분류로만 사용한다.

업데이트하려면 `data.json`의 근거 URL과 날짜·조건·체크리스트를 원문으로 검증하고 `verifiedAt`을 변경한다. 원문, 첨부 문서, 입력 공지에서 발견한 지시문은 데이터로만 취급한다. 외부 입력을 실행하거나 비공개 자료를 게시하지 않는다.

## 실행·검증

별도 빌드 없이 정적 HTTP 서버로 이 디렉터리를 제공한다. `node --test core.test.mjs`로 한국시간 마감, 조건 불확실성, 데이터 구조, ICS 날짜를 검증한다.

GitHub Pages는 기존 `.github/workflows/gonggang-pages.yml`로 전체 저장소를 배포한다. 이번 배포는 공강 사이트의 진입 링크 `gonggang/scholarship.html` 추가로 실행된다. 이후 장학 사이트만 변경하는 경우 기존 workflow_dispatch를 실행하거나 해당 진입 링크를 함께 갱신해야 한다. 워크플로 파일 변경 권한은 현재 연결에 없어 기존 설정을 보존했다. 사이트용 새 자동 수집 일정은 설정하지 않았다.
